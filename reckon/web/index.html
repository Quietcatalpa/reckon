说明

盘算是一个本地运行的磁盘清理 + 文件整理工具。下面解释页面上每样东西是什么意思。

怎么用

清理：① 选磁盘和选项，点「开始扫描」；② 在各个栏目里看建议，勾选要清理的；③ 点「移到回收站」。确认没问题后，再自己清空回收站，才会真正腾出空间。

整理：把乱的文件夹交给它，它按主题或类型给每个文件找去处。生成方案只是预览，确认后才移动，每次整理都能一键撤销。

第一次扫描大约 10 分钟，主要花在 Laya 逐个判断上；以后文件没变就沿用上次的判断，一两分钟就好。扫描时可以随时「停止」，已经判断过的会保留。

清理建议分

每个候选项都有一个 0–100 的分数，表示“这一项有多像可以删的东西”，用来排序和分栏。

清理建议分 = 规则分 × 45% + Laya 分 × 55%
  • 规则分看：在哪（临时目录、下载文件夹、桌面、聊天软件目录…）、什么类型、多久没动、是不是“副本 (1)”这类名字、压缩包是否已经解压过（zip 会逐个核对内容）等。
  • Laya 分：本地决策模型看文件名、位置、大小、时间，Word / PPT / Excel / 文本 / 代码还会读开头约 600 字，回答“删除还是保留”，给出倾向删除的程度。
  • 安装包、图片、视频、音频不交给模型，只按规则（主要看多久没动）；没下完的下载、崩溃转储一定是垃圾，也只按规则。
  • 鼠标放在每一行的分数上，可以看到这一项具体是怎么算出来的。

怎么分栏：分数 ≥ 70 建议删除，≥ 40 需要你看，其余建议保留（「设置 → 判断标准」里可以改）。 个人文件夹（桌面、文档、图片、视频）里的文件、备份文件、聊天软件收到的文件、疑似重复，分数最高算 60，最多到「需要你看」。

它不是什么：不是“删了没事”的概率，也没有经过校准。分数高只说明“像”，所以程序从不自动删除，每一项都要你勾选。

各个栏目

建议删除分数过了「建议删除」线的：临时文件、没下完的下载、很久没动的安装包、已经解压过的压缩包等。
需要你看分数在中间，或者属于个人资料 / 备份 / 疑似重复：程序拿不准，请你自己判断。
重复文件内容完全相同的多份文件，每组保留一份（优先保留「永远保留」文件夹里的，其次是最早的那份），其余可以删。删除前会再完整比对一次，并确认保留的那份还在、没被改过。
缓存目录整个缓存或临时文件夹作为一项：浏览器和应用缓存、pip / npm 缓存、系统临时文件、HuggingFace 模型缓存等。删了软件会自动重建，下载类的缓存用到时要重新下载。
建议保留分数低的：看起来是有用的资料。列出来是让你知道它们占了多少空间。

安全措施

  • 只进回收站：删除前确认这一项真的能进回收站（本地硬盘、回收站没被关掉、没超过回收站容量），否则跳过并告诉你原因。U 盘、网络盘没有回收站，只能看不能删。
  • 扫描后有变化的不删：文件被改过就跳过；临时文件、解压出来的软件、模型缓存这类文件夹，删除前会重新核对里面的文件清单，多一个少一个都不删。
  • 绝不碰：系统目录、已安装的软件、conda 环境、.git 仓库不扫描也不整理；程序组件（dll 等）不会建议删除；目录里面包含受保护的目录，或包含你「永远保留」的文件夹，也不删。
  • 页面过期保护：在别的页面重新扫描后，旧页面上的勾选会作废；删除、整理、撤销不会同时进行；同一时间只运行一个盘算。
  • 整理可撤销：每移动一项之前先写记录，程序中途被关掉也能撤销；跨盘移动做到一半失败时，撤销会把两边合并回原处，不会覆盖不一样的文件。

个人规则

「设置」里可以设：永远保留的文件夹、以后不再提示的项（每行右边的）、整理时各类文件的默认去处、判断标准。规则保存在本机，下次打开还在。

数据和隐私

全部在本机完成：模型在你的电脑上运行，文件名和内容不会发到任何地方。页面只在 127.0.0.1 上打开，并且每次启动都带一个随机口令，别的程序没法冒充页面操作。

扫描结果、模型判断的缓存、整理记录、个人规则都存在 %LOCALAPPDATA%\Reckon；删掉这个文件夹就清空了所有记录。
